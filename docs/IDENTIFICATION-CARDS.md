# 图鉴卡片

「标本照片 → 图鉴卡片」直接接收透明 PNG，不依赖照片工作流批次或 AI 引擎，需要 Photoshop。

## 使用

1. 添加 PNG 或文件夹（包含子文件夹）。按 `编号_中文名_拉丁名_D.png` 和 `_V.png` 配对。中文名末尾「雌」识别为雌，未标注默认雄；缺面、重复面和名称冲突会提示，不能导出对应条目。
2. 逐只修改中文名、拉丁名和性别。未鉴定隐藏两个性别符号。采集信息全部可空，支持粘贴一行 Markdown 或制表符表格，再点「整理粘贴内容」。
3. 采集文字按「采集点, 国家, 海拔, 日期」显示，例如 `Kwabena Sam Forest, Ashanti, Ghana, 1000m, 2025.4.28`。`Apr. 2026` 转为 `2026.4`，不补未知日期。可修改四项后点击「按上述四项更新文字」，也可直接编辑最终文字；歧义原文不会静默丢弃。
4. 刷新查看真实模板预览。正面左、反面右，以可见轮廓中心对齐。普通图侧边各留约 20 像素，长形可向下超出名义框最多 150 像素，自动避让文字。
5. 需要人工调整时点击「在 Photoshop 中调整」，调整并保存后，回到工具点击「完成调整并刷新」。未保存时不会自动保存或丢弃。刷新与文字更新保留人工位置，只有「重新自动排版」会重置构图。
6. 选择输出目录，导出当前或可用卡片。使用 Photoshop 快速导出 PNG，保留模板画布 4000 × 2250；命名为 `编号_编辑后中文名_编辑后拉丁名.png`。已有同名文件逐项询问覆盖，拒绝则保留旧文件。

模板、默认输出目录沿用当前配置；输出目录可更改。Shape 辅助框不会出现在预览或成品，85BG 背景及 Butterfly 组投影保留。

批量填写时，点击顶部「批量填写采集信息…」，粘贴 Markdown 或制表符表格。每条数据依左侧标本列表顺序对应一只，包含暂不可导出的条目。核对编号和采集文字后应用；行数不符时无法应用。需要为某只留空时保留一行空单元格（如 `| | | |`）。应用后仍可逐只修改。

## 工作文件与恢复

只有实际预览或处理的卡片才创建一份工作 PSD，修改与刷新复用该文件。确认最终 PNG 发布成功后清理工作 PSD，保留轻量清单与预览；失败或拒绝覆盖时保留工作文件。重开应用恢复未完成记录。

已成功导出的卡片若重新生成，会保留文字但无法恢复已清理 PSD 中任意人工细节。需要后续反复修改时，请在导出前完成调整。

原模板、输入 PNG 和用户其他 Photoshop 文档不作为清理目标。外部修改输入或模板后需要重新导入；删除/改型模板角色层会报告错误，不能自动重建覆盖人工修改。移除卡片是明确丢弃对应工作 PSD，输入与成品保留。

人工调整期间工具暂停自己的其他 Photoshop 自动任务；请勿同时从多个应用实例启动 Photoshop 处理。
