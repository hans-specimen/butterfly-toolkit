本记录对应 `489ff8f` 后的修复验证，最初验证时应用版本为 1.3.2 (7)，尚未提交或安装。随后用户授权合并、推送及安装，新安装版本准备为 1.3.3 (8)；实际交付状态以 Git 和安装应用为准。验证现有蒙版回放，不代表重新运行 AI 模型或用户最终画质认可。

## 行为

自动清理先建立 Alpha ≥128 的可信种子，经 ≥32 连通区域重建核心；多个有充分支持的核心同时保留。保护带按图像长边 1%（至少 3 px）计算，采用实际轮廓的截断 3–4 距离变换，不使用外接矩形。

远处紧凑淡斑要求均值 ≤8、90% 分位数 ≤16、无 ≥64 像素，同时不能呈现明显细长或稀疏结构。边带还要求沿画布边缘延展、至少 3 px 厚、宽高比 ≥12、厚度不超过长边 0.5%（至少允许 5 px），均值 ≤16、90% 分位数 ≤64、≥64 像素比例 ≤10%，且没有 ≥128 像素。一两像素宽的独立贴边片段保持不确定。所有参数集中在内部 `Policy`，不按标本名称判断。

与核心相连的区域不自动切断；远处沿边延展的分量即使 Alpha 为 40/110，也保留并提示检查。提示框定位远处候选部分。保留区域逐像素不变，`subjectSupport` 与非零 Alpha 严格一致。无可信核心时不猜测删除；人工半透明成品的完整布局、导出不依赖 AI 强核心门槛。

裁切、4K、素材紧裁都包含保存结果的全部实际非零 Alpha。报告带哈希和算法版本，绑定自动保存版本，首次自动几何变换转换位置；人工保存/定稿读取使旧诊断失效。没有报告的旧记录继续解码，不迁移蒙版。

清理按底图 Alpha 与原蒙版合成后的实际可见 Alpha 分类，再将保留/删除决定映射回原蒙版。保留值不重复乘底图 Alpha；极弱底图上合成后已经不可见的像素归零。增加了 Alpha 1×1 与 128×128 的失败复现和回归测试。
