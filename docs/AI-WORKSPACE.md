# AI 工作区

本文说明当前 Toolkit 的独立 AI 工作区及引擎接口。

## 连接与使用

1. 在 AI 页面工具栏的「AI 项目」中选择已配置好的引擎目录。Toolkit 不安装 Python 依赖，也不下载模型。
2. 在「AI 抠图」点击「添加待抠图片」，可多选 PNG 或 JPEG，无需人工答案。多选只批量导入，推理仍需逐张发起。
3. 选中图片，在检查器中选择 Mac GPU（`mps`）或 CPU（`cpu`），点击「开始抠图」。处理状态来自引擎，可取消当前推理。
4. 查看左右对比，使用共享缩放、平移、整图或关注区域定位；支持原图、人工参考和透明度模式，以及黑底、白底、透明格。没有人工参考的样本仅提供原图对比。
5. 完成后可在访达定位结果，或用「另存结果」导出透明 PNG。模型和已有测试批次可从工具栏重新选择或刷新。

项目目录与所选测试批次保存在本机偏好设置中；素材分组及结果关联保存在引擎目录的 `outputs/toolkit-ai/workspace.json`。图片解码、文件哈希与子进程阻塞读取在后台执行。

## 训练素材与分组

「训练素材」只显示带人工答案的配对样本。导入入口接收原图 PNG 和带透明通道的答案 PNG，不直接读取 PSD。

- 导入前检查扩展名、真实 PNG 类型、两图尺寸相同及答案带 Alpha；通过后复制到 `data/processed/toolkit-imports/<UUID>/`，不修改源文件。任一副本复制失败会清理本次导入目录。
- 尺寸一致不代表内容对齐。只有用户确认逐像素对齐，样本才标记为已对齐；未确认的配对仍可导入供检查。
- 同一只标本的正反面和全部裁切应使用同一标本组编号。训练、验证、测试或排除用途按整组保存，不凭文件名自动识别分组。
- 可选训练样本必须同时满足：有人工答案、已对齐、标本组非空且已确认、整组用途为训练。分组或用途改变后，不再合格的已选样本会被移除。
- 普通待抠图片交给引擎的 `import-image` 导入，返回记录必须没有人工答案；部分文件失败时保留成功项并汇总错误。具体图片编码与色彩支持范围由所连接引擎决定。

「模型训练」当前只准备任务名称与样本选择，这些准备信息不作为训练任务持久化。「创建训练任务」禁用；没有训练调度、训练进度或训练结果。「模型版本」展示引擎目录中的模型与验证信息，比较版本和选用训练版本按钮仍禁用。

## 文件与结果保护

- 导入配对记录保存原图与答案的 SHA-256。重新载入时，如文件变化、缺失或没有校验记录，会撤销原有对齐确认并提示重新检查。
- 独立推理完成后必须存在透明 PNG 与 Alpha PNG，并核对同目录 `result.json` 的 `inputSha256` 与当前输入内容；不匹配的结果不会关联到样本。
- 已保存结果记录包含输入、透明 PNG 和 Alpha PNG 的哈希。重新载入时校验三者，失效结果隐藏并说明原因；其他未载入批次的关联保留到该批次载入时再校验。
- 「另存」解析符号链接后的路径，拒绝覆盖原图、人工答案、已有 Alpha 或任何已有目标文件。需要另取文件名。

独立工作区不提供人工修图、自动几何对齐、自动识别同一标本或任意目录自动推理。模型的数值验证状态与视觉质量是不同信息，不能以数值通过代替缘毛、触角等细节检查。

## 引擎目录与命令契约

Toolkit 与 AI 引擎独立维护。选择的目录至少需包含可执行的 `.venv/bin/python` 和 `scripts/toolkit_bridge.py`；模型、测试批次及其他运行资源由引擎提供。应用以该目录作为子进程工作目录，并禁用 Python 输出缓冲和字节码写入。

独立 AI 工作区每次操作启动一个新进程，调用形式为：

```text
.venv/bin/python -u -B scripts/toolkit_bridge.py catalog [--run <测试批次目录>]
.venv/bin/python -u -B scripts/toolkit_bridge.py import-image --input <源图片>
.venv/bin/python -u -B scripts/toolkit_bridge.py infer --input <样本原图> --device <mps|cpu>
```

标准输出使用逐行 JSON 事件；标准错误写入临时日志，失败时用于诊断。进程正常退出且收到 `catalog`、`imported` 或 `completed` 终态事件才算完成；`status` 用于进度文字，`error` 提供错误原因。

目录事件中的 `catalog.schemaVersion` 必须为 `1`。目录提供模型、样本、测试批次路径及可选报告路径；导入事件提供 `sample`；推理完成事件至少需提供 `prediction` 与 `predictionAlpha`，结果目录还需有上述输入哈希记录。模型名称、revision、输入尺寸及可用性由目录返回，不在使用文档中固定某个版本。

## 与照片工作流的区别

外部 AI 引擎用于独立工作区的导入、抠图推理、结果比较与训练素材准备。照片工作流使用 Photoshop 选择主体和蒙版色阶，详见 [照片工作流](PHOTO-WORKFLOW.md)。

原照片流程的常驻 worker 协议及实测保留在 [历史验证记录](validation/2026-11-07-photo-workflow-performance-task-8.md)。
