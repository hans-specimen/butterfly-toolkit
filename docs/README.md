## 维护方式

同一事实只在所属主题文档详细说明，README 和本索引提供入口。文档更新应与代码一起核对，不保留已经完成的执行步骤作为待办，也不把历史分支、机器路径和一次测试总数写成永久状态。

2026-11-09 清理了已被现行文档取代的设计稿、执行计划与旧交接说明；尚未完成的候选择优门槛已迁入照片工作流文档。保留历史验证记录，因为其中包含不可由普通测试重建的真实像素比较、失败分析和性能对照。

本轮没有删除正式测试。旧 `staging` 源码副本中的测试不属于 Xcode 测试目标，随过时副本清理；新日志继续写入临时目录，必要结论提炼到有日期且明确范围的验证记录中。

随后全目录清理移除了本地旧应用构建、`staging` 中已完成的临时截图与结果副本、空的 `.work` 目录树、未采用的旧图标方案及重复图标导出。删除前已做项目目录外的恢复备份；当前图标原始设计、正式资源和本目录的历史实测记录继续保留。
